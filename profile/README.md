# Significant Dust

## DustSpeck

A real-time, geospatial signal field.

Participants submit short messages tied to a coarse location. The system aggregates unique voices across space and time, assigns emergent topic identifiers, and renders weighted topic labels directly on a map.

Users must submit a voice to unlock the current signal.

### System Priorities

- unique participants over volume
- coarse geospatial privacy (H3 + k-anonymity)
- projection over raw content
- optional contextual background separate from signal

### Goals

- provide a live “signal field” across space and time.
- enforce participation before visibility.
- protect privacy via coarse geo + k-anonymity.
- allow topic names to evolve without mutating stored events.
- offer optional, clearly separated contextual background.
